# Retail Customer Insights

## Project Overview
This project analyzes retail customer shopping data to understand purchasing behavior,
identify key trends, and generate actionable business insights.

## Objectives
- Analyze customer purchase patterns
- Identify factors influencing repeat purchases
- Compare online vs offline sales performance
- Support data-driven marketing and business decisions

## Tools & Technologies
- Python (Pandas, Matplotlib)
- SQL
- Power BI

## Key Insights
- Discounted products show higher purchase frequency
- Online channel generates higher order volume
- Customers with higher ratings tend to repeat purchases
- Seasonal trends significantly impact sales
